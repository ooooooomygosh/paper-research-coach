# 本地数据与访问边界

- 服务只监听127.0.0.1，不提供远程访问模式。不要转发工作台或Zotero端口。
- 启动URL片段含访问凭证，网页交换为HttpOnly、SameSite=Strict会话cookie后移除片段。API检查Host、Origin与凭证；跨站请求拒绝。不要分享启动地址。关闭服务后可删除数据目录中的session-token来轮换工作台凭证。
- Zotero键只保存在系统凭证库或当前进程，不写入数据库、导出、日志或仓库。用户可在Zotero高级设置撤销写入授权。
- 数据库包含笔记和修订历史；浏览器localStorage仅保留当前编辑草稿，用于断线恢复。共用电脑应使用自己的系统和浏览器账户。
- 原始PDF以只读方式使用。上传建立独立托管副本；批注导出另建文件，不覆盖源文件。论文换版需要确认并重新核实位置。
- PDF.js只渲染页面与文字层，不启用交互脚本。当前依赖锁定文件使用修复已知漏洞的版本，并在CI中检查依赖审计。
- 论文、网页、导入HTML与笔记都不是可执行指令。React以文本显示笔记，Zotero HTML仅提取文本，不直接嵌入页面。
- 同步限定用户选中的个人集合。第一版连接该条目的首个PDF附件；不会上传整篇PDF，也不会自动级联删除论文或附件。
- 书目核实只向 Crossref、arXiv 或用户配置的 OpenAlex 发送 DOI / 题名，PDF 不上传。OpenAlex key 使用系统钥匙串；第三方网络错误统一脱敏，避免查询参数中的凭证进入状态或导出。
- 工作台通过本机 Codex CLI 调用其配置的模型服务，适用该服务的数据设置。发送当前论文的阅读状态、当前页与选区；其他页通过绑定论文的读取工具访问，图像由用户勾选后附上。浏览器不接触模型凭证，CLI 原有配置不被覆盖。
- 阅读运行时使用只读沙箱，关闭命令执行与外部插件入口。研究记录通过绑定论文的工作台工具提交；PDF、笔记与导入的对话历史不作为行为指令。教练不能改变原话作者或笔记授权。

备份前停止工作台，复制整个应用数据目录，并另外保留它引用的PDF。热备份应使用SQLite backup API，不单独复制正在使用的.sqlite3文件。导出文件不包括凭证，但会包含用户选择导出的笔记。

报告问题时仅提交合成复现材料与脱敏错误描述。不要上传数据库、会话凭证、个人PDF、系统凭证库或未经同意的对话。
