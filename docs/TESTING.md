# 验证记录 · 2.0.0rc1

记录日期：2026-09-30。当前发布为预览版。软件测试、宿主行为测试与真人学习效果分开报告；未完成的真实 Zotero 往返测试是稳定版发布门槛。

## 软件与安装

在 macOS、Python 3.12.3 环境执行：**25 项自动化测试通过**。独立 Python 3.14.5 环境从 wheel 安装并启动成功。仓库 CI 另行验证 Ubuntu / Python 3.10、3.12；以 Actions 中对应提交的实际结果为准，不能把配置存在当成通过。

| 范围 | 实际检查 |
|---|---|
| 数据契约 | 原话中的空格、换行和 Unicode；用户与 AI 来源隔离；只读记录；关联论文一致性；修订历史 |
| 事务 | 操作 ID 幂等；并发更新只允许一个版本成功；失败原子回滚；重复导入 |
| 位置 | 页面与矩形边界；PDF 换版后旧锚点失效；旧笔记保留；重复摘录不猜位置 |
| 导出 | Markdown 与比较 CSV；表格公式转义；批注 PDF 使用核实位置，原始 PDF 摘要不变 |
| 服务 | 会话凭证、Host 与 Origin 检查；跨站请求拒绝；非 PDF 上传拒绝；仅回环监听 |
| 复习 | 可修改间隔、回答历史、帮助程度与到期时间 |
| 命令入口 | JSON 标准输入提交、上下文、恢复与导出走相同数据层 |

TypeScript 检查与生产构建通过；skill 元数据、渐进加载引用、JSON 资产和场景清单检查通过；本次 `npm audit` 报告 **0 个已知漏洞**。依赖审计是检查当时的结果。

wheel 中确认包含前端、PDF.js worker / 字体 / CMap / 解码资源、完整 skill 与第三方许可。安装后的界面从该独立环境启动，不依赖本地 Node.js。Windows 未实测。

## 实际界面与宿主连接

使用项目自行生成的三页合成论文完成浏览器操作，随后直接核对数据库：

- 文字选择和区域框选生成页索引及 PDF 坐标；点击笔记回到对应页面。
- 原话自动保存，刷新后保留；“已保存”和“AI 已讨论”分别呈现。
- 新建研究问题卡、保存复习回答与帮助程度、暂停并恢复阅读断点。
- 从当前 Codex 宿主读取新笔记，另建关联 AI 评论，再更新讨论状态；原话不被替换。
- 检查窄屏与桌面布局；修复 PDF 样式污染及窄屏论文切换入口。
- 用独立 PDF 渲染器查看导出的批注 PDF，确认高亮与合成原文位置相符。

这些是功能验证，没有学生参与，也没有测量理解提升。

HTTP 模拟集成覆盖：双向笔记与原生高亮、颜色与锚点、并发冲突、两侧删除待确认、服务重启、写入结果未知时幂等重试、断线重连、实例切换、授权拒绝/失效、外部或不可编辑批注保留、冲突解决失败、PDF 后续下载和 PDF 原地换版。

**本次未完成真实 Zotero 库测试。** 已确认本机安装 Zotero 10.0.4，但应用窗口不响应，本地 23119 端口拒绝连接；尚未进入其原生写入授权流程。没有修改 Zotero 数据库或强制终止应用。模拟接口不能证明真实版本的所有字段、权限和批注坐标都兼容。

稳定版发布前，在用户自行建立的隔离测试库/集合中完成以下检查，并记录实际 Zotero 版本与结果：

1. 原生授权、个人集合选择、合成 PDF 导入及本地附件定位。
2. 两侧分别新增、修改普通笔记、高亮、文字批注，重启双方后再次读取。
3. 同时修改保留双方版本；双方各删一次，确认前不删除本地论文或附件。
4. 撤销授权、关闭 Zotero、在写入后断线，再授权/重连后不重复写入。
5. 切换实例、不可编辑批注、带裁剪或旋转的 PDF、PDF 换版后坐标处理。

当前按所选个人集合和条目的首个 PDF 附件同步。集合成员移除或父条目消失时保留本地资料，不自动级联删除；首发不承诺多附件合并、群组库写入或 Zotero 内部数据库兼容。
