## 实际界面与宿主连接

使用项目自行生成的三页合成论文完成浏览器操作，随后直接核对数据库：

- 文字选择和区域框选生成页索引及 PDF 坐标；点击笔记回到对应页面。
- 原话自动保存，刷新后保留；“已保存”和“AI 已讨论”分别呈现。
- 新建研究问题卡、保存复习回答与帮助程度、暂停并恢复阅读断点。
- 从当前 Codex 宿主读取新笔记，另建关联 AI 评论，再更新讨论状态；原话不被替换。
- 检查窄屏与桌面布局；修复 PDF 样式污染及窄屏论文切换入口。
- 用独立 PDF 渲染器查看导出的批注 PDF，确认高亮与合成原文位置相符。

这些是功能验证，没有学生参与，也没有测量理解提升。

## Zotero：真实接口与模拟范围

在 Zotero **10.0.4** 的独立合成测试集合中，使用官方原生授权完成10项核心检查：精确保留空格和换行、普通笔记新增/修改、富文本回读、讨论状态不改写HTML、双方修改冲突、明确保留本地、原生区域批注新增、批注回读/回写、删除确认且不删除PDF。测试材料为项目自产，不是研究证据。授权键未写入测试报告。

实机发现并修正两个模拟接口缺口：客户端指定 key 的首次创建返回400；查询附件子项必须显式 `itemType=annotation` 才能读到批注。首次创建改为无键请求，并在 `relations` 中保存持久关联标记。提交内容与版本先入持久队列，恢复时按标记找回；结果未知且尚未找到远端对象时保留待核对状态，**不会盲目重复创建**。本地 Write-Token 是内存记录，不能单独提供服务重启后的去重保证。

HTTP模拟另覆盖授权拒绝/失效、断线、写入成功但响应丢失、实例切换、两侧删除、跨进程首次拉取、标签交叉修改、并发及换版。特殊外部批注的 `annotationIsExternal` 保护仅在模拟字段存在时验证；10.0.4实际JSON不提供该字段，尚不能声称所有外部批注识别均经过实机验证。未支持的批注类型保留为只读。

仍需扩充的实机范围：撤销授权与Zotero关闭重启、切换独立文献库、特殊不可编辑批注、裁剪/旋转PDF的原生坐标往返。按所选个人集合和主要PDF附件同步；不自动级联删除，不承诺群组库写入和多附件合并。

## OneDrive / Markdown

合成目录测试覆盖按内容去重、重复扫描、重命名/删除、文件尚在下载、卡片来源与论文关联、双侧编辑、输入事务中断、完整/半写导出恢复、符号链接路径保护与实例隔离。仅已完成的历史内容允许自动恢复导出映射；半截或不匹配文件进入冲突，选择工作台版本后另写完整新修订。

目录使用追加式 Markdown 修订文件，避免覆盖外部编辑器。新文件的未知作者身份不自动标为学生原话；AI卡片不会提高阅读进度或能力评估。后台服务运行范围为登录期间，电脑离线、睡眠或文件未下载时保留本地状态等待恢复。
