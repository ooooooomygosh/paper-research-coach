# DSH 1.4.1 · 按主题切换论文和批量翻译

- **阅读与翻译共用主题。** Zotero 同步读取已连接集合下的子集合。在阅读页的论文列表和批量翻译中可以按主题筛选、查看篇数，再搜索论文。
- **勾选当前结果。** 批量翻译可以勾选当前筛选结果。切换主题或搜索词后保留先前勾选，并提示有多少篇已选论文在当前结果之外。
- **从当前证据进入互动讲解。** 可从当前 PDF 页或选区进入，查看讲解所用的来源、保存问题草稿并继续追问。

macOS Apple silicon 用户可下载 `PRC-DSH-1.4.1-mac.zip`。完全退出 Harness，解压后双击 `安装.command`。已经使用 1.3.1 或更新版本的用户也可以在「设置 → 版本与更新」检查更新，待下载校验完成后重启 Harness。安装包随附 SHA-256 校验与更新清单。[安装、数据与恢复](../DEEPSEEK_HARNESS.md)

## English

- **Browse and translate by topic.** Zotero sync reads the child collections of your connected collection. The reading paper list and batch translation show topic filters, paper counts and search.
- **Select the current results.** Batch translation keeps earlier selections when you change topic or search and shows how many selected papers are outside the current results.
- **Open an interactive explanation from the PDF.** Use the current page or selection, see the evidence source, save a question draft and ask a follow-up.

The package is for macOS Apple silicon. Open `安装.command` from the extracted ZIP with Harness fully closed, or check for updates in Settings if you already use 1.3.1 or later. [Installation and recovery](../DEEPSEEK_HARNESS.md#english)
