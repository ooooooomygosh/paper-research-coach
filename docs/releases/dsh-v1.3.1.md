# Paper Research Coach for DSH 1.3.1

DSH 插件专属发布，工作台内核 **2.0.0rc15**。本次安装资产面向 **macOS Apple silicon**，真实宿主检查基线为 **DeepSeek Harness 0.2.2-rc.1**。

## 阅读与讲解

- 中文／双语选区提问保持当前语言和位置，点击证据再定位；带读可跟随当前视图。无法可靠映射时保留待核实状态。
- 讲解可进入应用内大阅读区，与 PDF 调整宽度对照，全屏或主动独立打开。追问草稿、当前讲解页和阅读位置保留。
- 四阶段软路线按速览／理解／研读调整；旧八步记录不覆盖，接续旧问题与位置。
- 新增选段、章节和全文对照批注页；逐段生成、停止续做、修订、共用用户笔记、可折叠图谱与离线 HTML。
- 修复宽图缩成小字、批注入口与设置复杂的问题。模型与并发等高级设置默认折叠。

## DSH 专属更新

1.3.1 增加 DSH 包更新流程：检查 `dsh-v*` 发布，验证宿主、平台与 SHA-256 后暂存；下次完全退出 Harness 并打开时安装。运行中的阅读进程不替换。设置显示实际插件版本、准备状态和手动检查。更新保留旧版和数据备份；独立 workbench wheel 更新器在 DSH 中仍关闭。

目前只提供 macOS arm64 自动安装资产；不兼容平台保持原版。旧版本首次升级需手动使用本安装包。

## 安装文件

- `PRC-DSH-1.3.1-mac.zip`：解压后双击顶层目录内 `安装.command`，操作前完全退出 Harness。
- `dsh-release.json`：DSH 更新清单。
- `PRC-DSH-1.3.1-mac.zip.sha256`、`SHA256SUMS`：安装包校验。

论文、译文缓存、笔记、对话和旧阅读记录保留在原数据目录。升级与回退需保持程序和数据快照匹配。

独立工作台 **v2.0.0-rc.15** 的 wheel/Skill 单独发布。Windows **1.2.0** 属于历史分发，本次未发布 **1.3.1 Windows ZIP**，macOS 包不可用于 Windows。
