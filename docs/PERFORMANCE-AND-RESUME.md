# 续读与交互验证

验证日期：2026-11-11。这里区分源码回归、隔离浏览器实验与原生宿主观察。测试材料均为合成内容，未向模型提交个人材料。

## 旧阅读如何继续

新版计划按旧阶段和同版本的有效完成前缀确定入口：阅读目标/暂定贡献→判断是否值得读，问题设定/方法→理解关键机制，证据→核查证据与边界，综合判断/研究启发/回忆→形成并回忆判断。保存原有目标、待答问题、下一步、游标及旧回执引用，不改写原记录；旧进度不会被解释成独立掌握。换文献版本时保留旧返回点供核查，不直接借用旧问题和坐标。

模型继续前须复用已有目标和最近真实回答，必要时读历史，避免重新介绍或无必要地要求重译。已有译本的使用仍依据其文件身份和来源版本。

对话历史恢复不依赖手动连接模型。前端先读取 canonical 会话，再建立事件流；事件流不可用时只读重试。迟到的初始响应不得覆盖较新的事件快照，失败时显示读取状态和重试入口。回归覆盖合成四消息自动恢复、事件流构造失败、空响应乱序和断线重试；这些测试验证缺陷类别，不断言任何一次原生界面取样的唯一原因。

## 浏览器测量

在同一台 Apple silicon Mac 上，以 Chrome headless（软件图形渲染、1440×1000、未限速）比较已安装 1.3.0 的公开前端资源与候选构建。每轮创建独立书库与 180 页合成文字 PDF，每页 52 行；讲解含 8 张有上限的流程图，每张 30 节点，合计 240 节点。没有访问个人 PDF 正文或真实模型账户。

| 指标 | 1.3.0 基线 | 候选构建 |
|---|---:|---:|
| 首个 PDF canvas 出现 | 378.5 ms | 404.6 ms |
| 图解阅读区打开 | 114.2 ms | 123.6 ms |
| rAF 帧间隔 p95 | 16.8 ms | 16.8 ms |
| 输入到下一 rAF p95（108 次输入） | 15.4 ms | 16.1 ms |
| 同时存在的 PDF canvas 峰值 | 5 | 5 |
| 滚动结束后 PDF canvas | 3 | 3 |
| 页面占位元素 | 180 | 180 |
| 超过 50 ms 的 long task | 0 | 0 |
| 采样末尾 JS heap | 41.8 MiB | 32.3 MiB |
| 仅切换展示方式时的生成请求 | 0 | 0 |
| 显式发送一次追问的模拟 POST | 1 | 1 |
| 上游模型调用 | 0 | 0 |
| 页面异常 | 0 | 0 |

这是单轮对照快照，存在调度、缓存和 GC 波动；不能据此宣称稳定提速。先前重复运行的候选首个 PDF 为约 450 ms、图解打开约 97 ms，也说明不应挑选单个数字作为性能提升结论。

代码审查同时修正了两个可避免的额外工作：展示区尺寸相同时不重复提交状态，并将 ResizeObserver 回调合并到下一动画帧；PDF 页共用稳定的批注点击回调，避免滚动时使全部占位页的 memo 失效。原有 PDF 活跃窗口和二分查页继续使用。

## 怎样复现

先构建 DSH 前端并安装可选 Playwright 浏览器依赖，再从仓库根运行：

```sh
PYTHONPATH=ports/deepseek-harness/upstream/src .venv312/bin/python ports/deepseek-harness/scripts/check_reading_performance.py
```

`PRC_BROWSER` 可指定 Chromium 可执行文件；`PRC_PERF_STATIC` 可指定基线的公开 static 目录，`PRC_PERF_LABEL` 指定报告标签。脚本输出到 `artifacts/verification/performance-*.json`。追问 HTTP 在浏览器中使用替身响应，只检查发送次数，未评估真实模型延迟或答案。

展示交互另由 `ports/deepseek-harness/scripts/check_learning_surface.py` 验证：展开、对照、分隔线、窄屏切换、草稿、独立窗口引用、弹窗阻断、Esc/焦点及 iframe 状态。

## 测量边界

- rAF 间隔不等于实际 GPU 帧率；输入到下一 rAF 也不是完整 INP 指标。
- JS heap 不包括全部原生 PDF、GPU 或进程内存。
- 180 页样本是文字/向量材料，不覆盖巨幅扫描页、特殊字体、超高分辨率图片及数千页文档。
- 240 节点分为 8 张受限子图，不证明单张千节点知识图流畅。
- Chrome 隔离页面不等于原生 DSH 中所有插件、网络和系统负载组合；模型响应和真实账户桥接耗时另测。
- 真人学习收益和论文论证正确性不由这些性能数字推出。
