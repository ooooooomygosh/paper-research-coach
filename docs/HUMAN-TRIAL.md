# 真人试读协议

目的：评估学生是否形成准确、独立且可迁移的研究判断。不要只问“喜欢吗”或统计生成了多少笔记。

参与者自愿加入，使用允许阅读的论文；无需上传个人研究记录。记录数据前说明保留范围、退出方式和匿名处理。默认不录音、不收集姓名。

1. 选择一篇与参与者背景相近、能在25—40分钟内完成一个关键判断的论文。教师先建立贡献、机制、证据边界的参考解释，并注明可接受的不同观点。
2. 前测：不使用AI，说明目前如何理解问题，以及会优先检查哪项证据。记录背景熟悉度与可用时间。
3. 试读：教练每轮一个动作；记录实际帮助程度、主动提问、原话与修正。允许直接要答案和拒绝笔记。
4. 即时测：暂时关闭论文与AI，用自己的话解释贡献、机制和最关键证据。再给一个变化条件，看能否预测结论的边界。
5. 延迟测：参与者同意的3—7天后重做核心解释或相近迁移任务。不要把单次即时表现当作长期学习。
6. 回顾：询问哪轮帮助最有用、哪轮让其被动或过载、记录是否忠实，以及希望在哪项能力减少帮助。

| 维度 | 0 | 1 | 2 |
|---|---|---|---|
| 贡献判断 | 只复述题目/结果 | 能描述改进，前作关系不清 | 能指出与最近前作相比改变的假设或能力 |
| 机制解释 | 只有模块名 | 局部因果链 | 能解释机制、关键条件和朴素方案限制 |
| 证据判断 | 接受作者结论 | 能定位证据 | 能区分支持范围与合理替代解释 |
| 迁移 | 直接照搬 | 注意到条件变化 | 预测变化后果，并提出最小检验 |
| 独立程度 | 依赖完整解释 | 需要提示 | 无提示重建关键判断 |

分数用于定位问题，不给“科研能力总分”。同时报告教师提示次数、完整解释次数和学生自主发起的证据检查次数。由不知道工具使用条件的第二位评分者复核一部分回答更可靠。

小样本先用于发现交互问题。若要主张学习收益，应预先确定主要结果、比较条件、分配方式、评分标准与分析；控制论文难度、先验知识、时间和练习效应。当前仓库尚无真人试验结果。
