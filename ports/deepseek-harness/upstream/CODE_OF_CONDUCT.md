# 行为准则 / Code of Conduct

这个项目帮助人认真读论文。我们希望讨论也一样认真、友善。

- **对事不对人。** 批评一个设计、一段代码或一条建议，不评价提出它的人。
- **欢迎新手。** 第一次读论文、第一次提 issue 的人和资深研究者一样受欢迎。用对方能懂的话解释。
- **尊重隐私。** 不贴别人的私人论文、笔记、对话或凭证；复现问题请用合成材料。
- **不容忍骚扰。** 包括人身攻击、歧视性言论、持续的不受欢迎的接触，以及公开他人信息。

我们采用 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 作为完整准则。遇到问题，请按 [SECURITY.md](SECURITY.md) 里的方式私下联系维护者；涉及安全或隐私的内容不要发在公开 issue 里。维护者可以编辑或删除违反准则的内容，必要时限制参与。

---

This project helps people read papers carefully; we want the discussion to be careful and kind too. Criticise ideas, not people; welcome newcomers; keep private papers, notes, conversations and credentials out of public threads; harassment is not tolerated. The full text is the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). To report a problem privately, use the contact described in [SECURITY.md](SECURITY.md). Maintainers may edit or remove content that breaks these rules and, if needed, limit participation.
