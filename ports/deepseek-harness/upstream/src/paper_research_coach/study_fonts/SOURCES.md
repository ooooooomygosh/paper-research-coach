# Embedded study fonts

Downloaded 2026-11-10 from Google Fonts' public repository. Original fonts are embedded without renaming or modification. Each font's SIL Open Font License accompanies both the package and exported HTML.

- Lora: https://github.com/google/fonts/tree/main/ofl/lora ; original `Lora[wght].ttf` saved as `Lora.ttf`.
- IBM Plex Sans: https://github.com/google/fonts/tree/main/ofl/ibmplexsans ; original `IBMPlexSans[wdth,wght].ttf` saved as `IBMPlexSans.ttf`.

These are fonts, not a remote runtime dependency. Exported documents make no font network requests.
