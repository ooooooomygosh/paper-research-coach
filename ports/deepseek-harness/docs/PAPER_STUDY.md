# 论文对照批注

在论文阅读工具打开“论文对照批注”，选择选段、章节或全文，先建立原文索引，再使用 Harness 账户逐段生成译文和分析。停止或关闭应用后，已完成段落保留；继续时跳过已保存分析。没有可靠文字层的页明确计数，不伪称已分析扫描页。

HTML 显示原文、中文译文、段落功能、逻辑角色、待核查处及当前用户批注快照。高亮引文必须唯一匹配该段原文，所有文本转义后输出。原文不可通过分析修订修改。已有笔记按原始记录 ID 引用，不复制为新笔记。导出无外部网络依赖；三种图谱采用可折叠 DOM 节点图，方法节点按段内步骤串联，概念节点按来源分组，论证节点串联候选主张、原文依据和待核查处。节点定位经宿主校验当前 iframe、研读身份、修订号和段落身份。Lora 与 IBM Plex Sans 使用随包的原始 TTF 并内嵌到离线文件，OFL 许可同时保留。

API：`/api/workspace/studies` 创建/列出；`/{id}` 获取；`/{id}/generate` 使用既有 jobs 生成；`/{id}/html` 查看/导出；`/{id}/paragraph/{paragraph_id}` PUT 以 revision 和 analysis 修订分析，保存此前分析版本。停止使用现有 job cancel API。

当前能力边界：章节由可识别标题推断，未识别时按开篇分组；已附入对应 PDF 整页图供公式与图表核验，尚未自动裁剪单独区域；预览来源定位由宿主的 `onLocate` 完成，离线文件支持文内跳转。总览通过账户单独生成候选主张、强处和待核查处，要求引文匹配传入片段；每块最多40段、24000字，所有段落分块摘要后递归合并，块结果持久保存；每段来源片段最多1000字，页面明确展示这一范围，不显示为独立全文评审。在线批注编辑经研读专属接口核查论文作用域与用户身份，再使用原 Note 的修订号和提交接口。
