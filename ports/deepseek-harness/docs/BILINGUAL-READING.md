# 双语研读与讲解阅读区（1.3.0）

## 日常使用

在原文、中文或双语 PDF 上划线后可以直接提问。局部提问不自动翻页；点击依据才定位，带读可跟随当前语言。定位依据不足时保留当前位置并提示。译版截图绑定实际文件，尚未对应原文的材料保持待核实。

点击讲解的放大入口进入大阅读区，可与论文对照、全屏或明确打开独立窗口。切换显示不会重新请求模型。追问草稿和当前讲解页保存在会话中。PDF 页面小批注按钮用于查找正文；下载按钮生成含批注的独立副本。

四阶段路线按速览、理解、研读调整任务；阶段可跳转和暂放。旧八步原始记录保留。速览以是否继续读为目标；理解包括机制、证据、边界和真实回忆；研读再选推导或最小检验。提供帮助不等于独立掌握。

“论文对照批注”支持当前选段、章节或全文，先建立带版本的段落索引，再逐段翻译和分析。可以停止、继续、重试；已完成内容保留。页面中的原文、译文、AI 分析与用户笔记分别显示；用户批注沿用原记录，编辑检查修订号。单文件 HTML 包含字体、图像和批注快照，离线可读。

## 内容范围

章节标题识别为启发式，应核对所选范围。扫描页没有可靠文字层时使用图像提问。公式与图表提供原页核验图，不声称已自动重建全部公式。图谱表示分析中的来源关系，AI 推断保持标识。候选总览标出实际参与汇总的段落范围。

## 数据与恢复

阅读计划使用独立版本表，不覆盖旧 Session。升级前应使用 SQLite backup API 制作一致性快照（不能仅复制活跃 WAL 数据库文件）。回退使用匹配版本的快照；不要让旧程序保存新版独有记录。原始 PDF 不改写，Zotero 原附件不接收译本坐标。HTML 是导出时的快照，外部修改不自动回传。

## 可重复检查

前端：两边 frontend 的 npm test 与 npm run build。后端：分别用根 src 和 DSH upstream/src 运行 pytest；新增阅读计划、译本映射、图像上下文及对照材料测试使用隔离数据。DSH Node 测试通过 PRC_TEST_PYTHON 指定已装依赖的 Python。离线示范为 examples/study-demo/synthetic-study.html，全部内容明确标为合成材料与预设分析。

真实宿主账户、个人论文、Zotero 实写与学习收益应分别验收，不能从合成响应或源码测试推断。
