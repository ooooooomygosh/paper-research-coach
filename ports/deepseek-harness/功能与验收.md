# 功能覆盖与验证

Paper Research Coach 内置插件 1.2.0，基于工作台 2.0.0rc13；宿主适配基线为 Windows x64 / DeepSeek Harness 0.2.1-rc.5。

| 功能 | 实现与验证 |
|---|---|
| 原版阅读工作台 | 保留 PDF.js、八章主线、任务卡、支线、复盘树、笔记与定位、研究脉络、想法、复习和导出；原版回归测试 |
| Harness 账户 | 通过宿主 ctx.llm 和 deepseek-account 适配器；桥接协议与取消测试、合成材料真实账户冒烟 |
| PDF 高亮 | 文字节点选区、按行合并去重、原生选区与草稿避免重复绘制；高亮与浮层回归、Windows 桌面观察 |
| 翻译与书库同步 | BabelDOC 0.6.4、中文/双语 PDF、Zotero/目录同步；合成 PDF 真实账户翻译与文字层检查。未在真实 Zotero 书库执行写入测试 |
| 知识库学习 | 固定版本 Learn from Materials 的实际提取器、来源映射、六模块模板、方法库与检索；逐字引文、版本笔记、恢复、练习、问答和导出测试 |
| 交互式讲解 | 固定版本 Answer me with HTML 的实际渲染器和图表/公式/问答组件；账户生成、编辑草稿、主题、修订、历史只读、HTML 导出测试 |
| 阅读界面改版 | 独立 SVG 控件图标、无高光样式、顶部全局入口、讲解表单折叠；本地合成材料浏览器观察及前端回归 |
| 标准阅读 | 带出处的七环节与 METHOD.md 综合提示，本地一键导出；下载内容与不触发模型测试 |
| 可操作组件 | 概念、步骤、比较、参数、证据五类；结构与数值校验、真实渲染器 DOM 交互、原文逐字匹配与换版拒绝、隔离页面带回问题与定位、历史和导出 |
| 多格式输入 | 实际提取两页中英文 PDF、DOCX、PPTX、EPUB；核对中文 CID 字体、物理页码、原文保留及无文字层失败提示 |
| 可分发安装器 | 隔离安装、重复安装、失败回滚、卸载、保留其他插件与用户数据、拒绝损坏包及不兼容宿主；完整运行库复制及真实宿主归档的隔离安装/卸载 |

1.2.0 本地源码验证：233 项 Python 测试通过、3 项跳过；120 项前端测试、20 项 Node 测试通过，类型检查和生产构建通过。按现有 Windows 验证脚本排除 POSIX 安装脚本测试。账户响应使用合成替身；浏览器预览使用隔离的合成 PDF 与本地测试传输，不证明原生 Harness 鉴权或真实账户输出已通过。

以下为 1.1.0 历史验证：209 项 Python 测试通过、7 项跳过；115 项前端测试、7 项 Node 测试通过。曾检查实际登录账户的合成材料构建、学习问答与互动页生成，以及桌面入口、嵌入页交互、问题带回和重启持久化。本次未重新执行真实账户冒烟、原生宿主安装或二进制发包。

公开源码的重复验证入口为 scripts/verify_source.py，只运行本地测试、类型检查与构建。真实账户和桌面检查需要自己的 Harness 环境，操作见 [README.md](README.md)；个人账户收据、桌面日志和安装归档不随 Git 提交，也不能根据单元测试推定这些检查已执行。

同名概念按来源单元保留不同含义；单元笔记和练习按版本保存。知识库回答的支持范围只描述本次检索片段。历史交互讲解只读，可导出；继续生成需要返回当前草稿并核对来源。模板内主题、画像和页内笔记按知识库共享，方法搜索使用当前发布版本。

限制：自动学习以提取文字为依据，未独立核实扫描页和图像细节；处理片段计数和引文匹配不等于语义完整性或教学效果验证。练习答案为模型参考答案，进度不代表掌握度。集成报告不声称执行了上游 finalize 的独立审查。macOS 沿用主线的源码构建与安装方式，本次未在本机进行原生宿主验收；没有其他 Harness 版本的兼容性结论。
