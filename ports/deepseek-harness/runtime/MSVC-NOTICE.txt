Microsoft C/C++ runtime libraries

The Python runtime directory contains unmodified, digitally signed Microsoft
x64 C/C++ runtime libraries (14.50.35719.0). They provide application-local
dependencies for the interpreter and native Python extensions, including
ONNX Runtime. They are proprietary Microsoft components and are not relicensed
under the workbench's MIT license or BabelDOC's AGPL license.
